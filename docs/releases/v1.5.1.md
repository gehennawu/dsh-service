# v1.5.1（2026-09-11）

v1.5.1 修复 DSH 内置渠道的额度查询自动识别，并改进版本卡排版。

## 新增 / 修复

- **内置渠道的额度查询自动识别**：直接启用 DSH 内置渠道（OpenCode Go、智谱 GLM Coding Plan、OpenRouter、DeepSeek、小米 MiMo Token Plan）而**没有手填 baseURL** 时，额度行以前会一直停在未适配状态，或提示「该供应商未配置 baseURL」。现在按渠道名自动识别并查询各自官方端点；OpenCode Go 使用 DSH 内置注册表里的默认端点 `https://opencode.ai/zen/go/v1/usage`。仍然只向该渠道官方域名请求，未适配的路由绝不外呼，声明了其他域名的路由不会被改道。
- **版本卡排版**：「（适配 DSH …）」声明回到插件版本号之后——宽面板内联同行，窄设置面板里由三行收成两行，不再独占整行，也不与更新状态互相挤压。
- **支持声明上限上移至 DSH 0.1.5-rc.2**：与 rc.2 逐字核对后确认无适配改动，仅上移声明；`0.1.6-alpha.0` 及以上仍标红警示。

## 兼容性与升级提示

- 本版本已按代码路径适配 DSH `0.1.1-rc.2` 至 `0.1.5-rc.2`；DSH `0.1.6-alpha.0` 及以上版本尚未验证。
- 从 1.4.x / 1.5.0 升级无需修改任何配置；已显式填写 baseURL 的路由行为完全不变。
- 本版本通过 340 项自动化测试。

## Added / Fixed

- **Automatic quota recognition for built-in channels**: enabling a DSH built-in channel (OpenCode Go, Zhipu GLM Coding Plan, OpenRouter, DeepSeek, Xiaomi MiMo Token Plan) with **no hand-written baseURL** used to leave the quota row unadapted, or report "this provider has no baseURL configured". Rows are now recognized by channel name and query each vendor's official endpoint; OpenCode Go uses the default endpoint from the DSH built-in registry (`https://opencode.ai/zen/go/v1/usage`). Requests still go only to that vendor's official host, unadapted routes never make a request, and routes that declare another endpoint are never rerouted.
- **Version card layout**: the "(Adapted for DSH …)" notice is back next to the plugin version — inline on wide panels and folded from three lines to two in the narrow settings panel, so it no longer takes a line of its own or collides with the update status.
- **Support statement ceiling raised to DSH 0.1.5-rc.2**: verified line by line against rc.2 with no adaptation changes required; `0.1.6-alpha.0` and later are still flagged in red.

## Compatibility and upgrade notes

- This release has been adapted for DSH `0.1.1-rc.2` through `0.1.5-rc.2`; DSH `0.1.6-alpha.0` and later are unverified.
- Upgrading from 1.4.x / 1.5.0 requires no configuration change; routes with an explicit baseURL behave exactly as before.
- This release passes all 340 automated tests.
