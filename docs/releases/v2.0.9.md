# v2.0.9（2026-10-15）

## 新增 / 修复

- **DSH 0.2.1-alpha.3 兼容**：兼容范围放宽至 `>=0.1.1-rc.2 <0.2.1-alpha.4`，适配 0.2.1-alpha.3 凭据来源优先级反转（托管存储优先，环境变量提供的值不再标记只读）；完成目标版本真实会话子代理派发闭环验收与旧宿主回归。
- **子代理独立 Agent Preset 支持**：对接 0.2.1-alpha.3 宿主 `agentPresets` 注册表服务，支持为派生子代理统一指定独立 Agent 预设；按 provider 能力与非继承上下文严格门控，调用方显式指定的预设始终优先；旧版宿主平滑降级。
- **混合协议渠道提示**：识别 pi-ai 1.1.0+（DSH 0.2.1-alpha.3 起）中 `azure` 等混合协议目录，在渠道模板选择与编辑时提示「路由级协议将覆盖全部模型」，防止多协议渠道模型被误套协议。
- **额度适配与模型图标**：新增三渠道额度适配并完善模型图标解析映射；模型配置说明文档接入完整界面截图。
- **模型发现与凭据链路加固**：补齐 Responses 协议模型发现与凭据更新测试链路，强化设置表单安全保护。

## npm 安装 / Install from npm

在 DSH 插件管理页输入：

```text
@gehennawu/dsh-service@2.0.9
```

或使用命令行（将 `web` 换成你的 Profile 名）：

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.0.9
```

精确版本号可避免 pnpm 发布观察期自动回退到旧版本；新发布版本仍可能包含尚未发现的问题。

## Added / Fixed

- **DSH 0.2.1-alpha.3 compatibility**: compatibility range expanded to `>=0.1.1-rc.2 <0.2.1-alpha.4`, adapting to 0.2.1-alpha.3 stored-credential precedence (managed store takes priority over process environment without marking refs as read-only). End-to-end delegation and regression tests verified on both target and legacy hosts.
- **Independent Agent presets for subagents**: connects to the `agentPresets` registry service in 0.2.1-alpha.3+, allowing users to configure an independent preset (role and tools) for delegated subagents. Strictly gates on provider capabilities and non-inheriting context; explicit delegation presets always take precedence, with graceful fallback on legacy hosts.
- **Mixed-protocol provider notices**: detects mixed-protocol provider catalogs (such as pi-ai 1.1.0+ `azure` in DSH 0.2.1-alpha.3) and warns in template selection and route editing that route-level protocols override every model on the route.
- **Quota adapters and model icons**: adds quota support for additional provider kinds and refines icon mappings; updates documentation with model configuration screenshots.
- **Model discovery and credentials hardening**: completes Responses model discovery and credential update regressions, strengthening configuration draft safety.

Enter `@gehennawu/dsh-service@2.0.9` in DSH’s plugin manager, or run the command above with your Profile name. Pinning avoids automatic fallback during pnpm’s release cooldown; newly published versions may still contain undiscovered issues.
