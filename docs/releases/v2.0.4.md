# v2.0.4（2026-09-30）

v2.0.4 带来多项移动端交互与体验优化，包括滑动沉浸全屏隐藏抽屉图标、模型选择按钮自适应零截断并常驻思考程度与厂家图标、移动端模型弹窗隐藏搜索框避免软键盘误弹，以及健康诊断项优化。

## 新增 / 修复

- **优化 · 移动端滑动沉浸全屏同步隐藏左上角抽屉图标**：进入对话框隐藏全屏阅读模式（滑动沉浸态）时，左上角侧栏抽屉图标（FAB）与顶栏和右上角右侧栏展开按钮同步向上滑出并平滑淡出，彻底消除全屏阅读区的孤立悬浮图标；上滑、点击「回到底部」浮钮或聚焦输入框时同步平滑复位。
- **优化 · 移动端模型选择按钮自适应零截断与思考程度常驻**：放宽官方 45cqw 硬限宽，使测宽基于真实无损文字；空间充裕时完整显示「厂家图标 + 模型全名 + 思考程度」（零截断）；空间不足时（小屏手机、长模型名或被其他第三方插件占用工具栏），模型全名自动收缩为紧凑态，但**思考程度（如 High / Low）与厂家品牌图标永远保持显示（`[厂家图标] High ▾`）**，无思考程度的模型则收成 45px 纯图标钮，全程单行不折行、零溢出、零尴尬截断。
- **优化 · 移动端模型选择弹窗隐藏搜索框（防软键盘误弹）**：移动端点击进入模型选择二级菜单时，隐藏带有 autoFocus 的「搜索模型…」输入行，彻底杜绝触屏点击时系统软键盘强行弹出遮挡菜单与屏幕的痛点，模型列表直接置顶展现更清爽。
- **优化 · 健康诊断会话统计索引失败调整为提示**：健康诊断中，模型统计索引出现单会话解析失败时由 warning 调整为 info 提示，符合「部分成功」语义，不再误点亮诊断标签的警告态。
- **重构 · 移除插件兼容性诊断功能**：清理已完成历史使命的插件兼容性扫描模块及其相关测试与文件引用。

## Added / Fixed

- **Optimized · Synchronized drawer icon hiding in mobile fullscreen immersion**: when entering chatbox-hidden fullscreen reading mode (scroll immersion), the top-left drawer icon (FAB) slides up and fades out smoothly in sync with the header and top-right sidebar button, eliminating orphan floating icons; smoothly restores upon swiping up, tapping back-to-bottom, or focusing.
- **Optimized · Mobile model selector untruncated auto-fit with persistent reasoning effort & brand icon**: relaxes the official 45cqw clamp so measurement reflects natural unclipped text; when space allows, displays brand icon, full model name, and reasoning effort without truncation; when space is tight (narrow screens, long model names, or tools added by other plugins), the model name collapses into compact form while **the reasoning effort (e.g. High / Low) and vendor brand icon remain persistently displayed (`[brand icon] High ▾`)**, while models without reasoning effort collapse into a 45px icon button, with zero wrapping and zero awkward clipping.
- **Optimized · Mobile model menu search row hidden to prevent virtual keyboard popup**: hides the autoFocus "Search models…" input row when opening the model selection menu on mobile, preventing mobile on-screen keyboards from forcefully popping up and obscuring the screen, presenting the model list directly.
- **Optimized · Health diagnostics session usage index failure adjusted to info**: changed failed session index counts from warning to informational, matching partial-success semantics without triggering alarms on the diagnostics tab.
- **Refactored · Removed retired plugin compatibility diagnostics**: cleaned up legacy plugin compatibility scanner and its associated tests and file references.
