# v2.0.1（2026-09-29）

v2.0.1 适配最新发布的 DSH `0.2.0-rc.2`：修复官方模型选择器列表重构导致的弹窗分组标题厂家图标丢失问题，并保持对老版本宿主的完全向下兼容；同时将 DSH 兼容支持声明扩展至 `0.2.0-rc.2`（已在真机挂载运行并完成全量验证）。

## 新增 / 修复

- **修复 · 模型选择弹窗厂家图标适配 DSH 0.2.0-rc.2**：官方在 0.2.0-rc.2 中将模型选择弹窗列表重构为 `MenuGroup` 共享原语，原类名 `_7KE1Ra_groupTitle` 被移除（产物命中归零），导致弹窗内的厂家分组图标静默消失。本版本选择器升级为 `[class*="_7KE1Ra_groups"] [data-menu-group-heading], [class*="_7KE1Ra_groupTitle"]` 双选，优先匹配 `0.2.0-rc.2` 引入的官方属性 `data-menu-group-heading`，同时保留旧类名兜底，无缝兼顾新旧版本宿主。
- **兼容 · 支持声明扩展至 DSH 0.2.0-rc.2**：对 rc.1→0.2.0-rc.2 真实窗口（187 commits）进行源码级与 npm 产物级深度审查，确认宿主 RPC（60 个端点）、会话持久化、设置面双协议、9 个 slot key 与 24 个主题令牌全部稳定零漂移；官方长期存在的 Client Inspect 挂起缺陷亦在 rc.2 正式修复；`engines.dsh` 上界放宽至 `<0.2.0-rc.3`，并已在 DSH `0.2.0-rc.2` 真机挂载运行验证。
- **修复 · 移动端面板页顶部头行让位**：收敛抽屉钮让位规则，优化窄视口下插件设置面板的标题排版。
- **文档 · 安装指南补充三种来源与安装源**：图形安装步骤补齐 npm 包名、GitHub 仓库地址与本地目录三种形式，并说明中国大陆镜像源的选择与作用范围。

## Added / Fixed

- **Fixed · Model selection popup provider icons adapted for DSH 0.2.0-rc.2**: upstream 0.2.0-rc.2 refactored the model picker menu groups with the `MenuGroup` shared primitive, removing the local `_7KE1Ra_groupTitle` class and causing group-heading icons to silently disappear. The selector has been updated to `[class*="_7KE1Ra_groups"] [data-menu-group-heading], [class*="_7KE1Ra_groupTitle"]`, matching the new `data-menu-group-heading` attribute on 0.2.0-rc.2 while maintaining backwards compatibility with older hosts.
- **Compatibility · Declared support through DSH 0.2.0-rc.2**: a source-level and artifact-level review of the full rc.1→0.2.0-rc.2 window (187 commits) confirmed that host RPC (60 endpoints), session persistence, dual settings protocols, 9 slot keys, and 24 theme tokens show zero drift; the long-standing Client Inspect hang defect is also officially resolved in rc.2; `engines.dsh` upper bound is updated to `<0.2.0-rc.3`, and real-host mounting on DSH `0.2.0-rc.2` is operational.
- **Fixed · Mobile panel top-row layout**: refined drawer toggle avoidance rules and heading layout for narrow viewports.
- **Docs · Installation guide details three sources and mirrors**: documented package name, GitHub repository URL, and local path options in the GUI installer alongside npm registry mirror guidance.
