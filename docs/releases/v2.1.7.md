# v2.1.7（2026-11-19）

## 会话管理

- **修复单条和批量归档误报「归档计划过期或状态已变化」**。真实的计划过期、会话状态变化及工作树风险仍会在提交前检查。
- **按工作树风险确认归档**。只有宿主确认所有选中会话都没有自己创建的工作树记录时，才会直接归档；有候选或无法判断时，先展示后果再确认。归档可能触发宿主清理符合条件的目录；取消归档不会恢复文件。若需要保留目录，先在官方 worktree 配置中启用 `retainOnArchive`。
- 会话内容搜索优先使用 DSH 官方全文索引，索引不可用时继续使用回退搜索。

## 稳定性与性能

- 修复备份预检复用时的重新校验和界面刷新回归；减少重复的备份预检与模型目录请求，加快权限深检。
- 减少启动时重复的版本请求，以及子代理、用量和健康面板不必要的后台轮询。
- 兼容声明仍为 `>=0.1.1-rc.2`，不设上界。DSH `0.2.2-rc.5` 已验证加载、基础界面、设置入口及只读 RPC；本次未验证 rc.5 新的默认网页搜索路径或真实工作树清理。

## Sessions

- **Fixed single and batch archives incorrectly reporting that the archive plan had expired or state had changed.** Genuine expiration, session state changes, and worktree risks are still checked before submission.
- **Archive confirmation is based on worktree risk.** Archiving proceeds without a confirmation dialog only when the host verifies that none of the selected sessions has a worktree creation record of its own. If a candidate exists or the risk is uncertain, the consequences are shown first. Archiving may trigger host cleanup of eligible directories; unarchiving does not restore files. Enable `retainOnArchive` in the official worktree configuration first if you need to keep a directory.
- Session content search prefers DSH's built-in full-text index and falls back when it is unavailable.

## Reliability and performance

- Fixed revalidation of reused backup preflight results and UI refresh regressions. Reduced duplicate backup preflight and model directory requests, and sped up deep permission checks.
- Removed duplicate startup version requests and reduced unnecessary background polling for subagents, usage, and health.
- The compatibility range remains `>=0.1.1-rc.2`, with no upper bound. Loading, basic UI, the settings entry, and read-only RPCs were verified on DSH `0.2.2-rc.5`; its new default web-search path and actual worktree cleanup were not tested.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.7
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.7
```

升级后重新加载插件或重启 DSH，再刷新浏览器页面。 / Reload the plugin or restart DSH after upgrading, then refresh the browser page.
