# v1.9.7（2026-09-23）

v1.9.7 扩展 DSH 兼容声明至 `0.1.7-alpha.2`，并包含兼容性提示修正与子代理回退改进。

## 新增 / 修复

- **兼容 · 支持声明扩展至 DSH 0.1.7-alpha.2**：alpha.2 源码对照未发现新的插件破坏面，`engines.dsh` 上界更新为 `<0.1.7-alpha.3`。本轮当前运行环境已是 alpha.2；隔离 profile 真机挂载、npm 产物 CSS 哈希词干对照与若干 GUI 回归尚未完成。本声明不代表这些项目已验证。升级前请注意 DSH 会话数据不支持跨版本降级恢复。
- **修复 · 兼容性扫描提示与详情卡配色**：兼容性扫描中 settings-scope 相关项目降为提示级；详情卡颜色随兼容档位展示。
- **修复 · 子代理运行期模型回退**：子代理请求遇到限流、服务器错误、超时/传输错误、空响应或额度耗尽时，若仍有配置候选则切换到下一模型重试；用户取消、参数/配置错误、上下文超限等不触发轮换，候选耗尽不循环。关闭子代理路由功能后，不再覆盖已轮换的模型路由。

## Added / Fixed

- **Compatibility · Declared support through DSH 0.1.7-alpha.2**: source review found no new plugin breakage in alpha.2, so `engines.dsh` now has an upper bound of `<0.1.7-alpha.3`. The current runtime is alpha.2; an isolated-profile host launch, npm-artifact CSS hash-stem comparison, and several GUI regressions remain unverified. This declaration does not claim those checks passed. DSH session data is not downgrade-restorable across versions.
- **Fixed · compatibility-scan hints and detail-card colours**: settings-scope compatibility findings are now informational, and detail-card colours follow the compatibility severity tier.
- **Fixed · runtime subagent model fallback**: on rate limits, server errors, timeouts/transport errors, empty responses, or quota exhaustion, a subagent switches to the next configured model and retries when a candidate remains. Cancellation, argument/configuration errors, and context overflow do not rotate; exhausted chains do not loop. Disabling subagent routing also stops overrides to an already-rotated model.
