# v1.9.8（2026-09-23）

v1.9.8 扩展 DSH 兼容声明至 `0.1.7-rc.1`（已通过真机挂载验收），并修正移动端跳转箭头与官方按钮的重复偏移。

## 新增 / 修复

- **兼容 · 支持声明扩展至 DSH 0.1.7-rc.1**：rc.1 源码对照（alpha.2→rc.1 全部 156 个提交、十个接缝文件逐字节复核）未发现新的插件破坏面，`engines.dsh` 上界更新为 `<0.1.7-rc.2`；已通过 DSH `0.1.7-rc.1` 真机挂载验收。rc.1 新增的插件版本兼容门禁只读取 `peerDependencies`，本插件无该声明，不受门禁约束、无需版本豁免。旧版 DSH（`>=0.1.1-rc.2`）兼容保持不变。升级前请注意 DSH 会话数据不支持跨版本降级恢复。
- **修复 · 移动端「上一条用户回复」箭头位置**：自有上箭头的水平位置本就按官方「回到底部」按钮的实测右缘计算，此前却被同时套用官方按钮的贴边平移，造成重复右移（实测偏差 28px）；现仅官方按钮参与平移，两枚按钮在移动端恢复对齐。

## Added / Fixed

- **Compatibility · Declared support through DSH 0.1.7-rc.1**: a source review of the full alpha.2→rc.1 window (156 commits) with byte-level re-checks of ten seam files found no new plugin breakage, so `engines.dsh` now has an upper bound of `<0.1.7-rc.2`; real-host acceptance on DSH `0.1.7-rc.1` has passed. The plugin-version compatibility gate introduced in rc.1 reads only `peerDependencies`; this plugin declares none, so the gate does not apply and no version exemption is needed. Older DSH releases (`>=0.1.1-rc.2`) remain supported. DSH session data is not downgrade-restorable across versions.
- **Fixed · mobile user-jump arrow position**: the "previous user reply" arrow's horizontal offset is already computed from the official "back to bottom" button's measured edge, but it also received that button's edge-shift transform, doubling the shift (a measured 28 px drift). Only the official button is shifted now, restoring alignment on mobile.
