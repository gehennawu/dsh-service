# v2.1.8（2026-11-22）

## 兼容性与修复

- 适配 DSH `0.2.3-alpha.2` 的 WebServer 和会话状态服务。运维路由会在 WebServer 就绪后挂载，并在其替换后重新挂载。待审和提问通知同时支持新版独立状态服务与旧版状态属性。
- 运维 RPC 和备份下载只接受回环连接及回环 HTTP Host；RPC 仍由宿主鉴权。远程登录不会放宽此限制，请勿通过反向代理向远程客户端转发这些路由。
- 概览重新显示持久化会话数。进入概览时按需读取，不参与健康轮询；读取前或不可用时显示 `—`，切页前的响应不会覆盖当前结果。
- 在支持新版会话面板的宿主上，宽度不超过 560 px 时，官方面板开关移至标签行右侧，不增加计数；更宽的视口保持官方位置。
- 模型渠道快照保留宿主配置的图片数量预算和尺寸上限；普通编辑保留原值，插件不会设置或取消设置这两个字段。

兼容范围仍为 `>=0.1.1-rc.2`，不设上界。新版宿主的验证基线为 `0.2.3-alpha.2`。

## Compatibility and fixes

- Adapted to the WebServer and session-status services in DSH `0.2.3-alpha.2`. Maintenance routes mount when WebServer becomes available and remount when it is replaced. Approval and question notifications support both the new standalone status service and the older status property.
- Maintenance RPCs and backup downloads require both a loopback connection and a loopback HTTP Host. RPCs still require host authentication. Remote login does not lift this restriction; do not forward these routes to remote clients through a reverse proxy.
- The Overview shows the persisted-session count again. It fetches the count on entry, separately from health polling, and shows `—` while loading or when the count is unavailable. Late responses from a previous visit are ignored.
- On hosts with the new session panel, viewports up to 560 px move the official toggle to the right side of the tab row without adding a count. Wider viewports retain the default position.
- Model channel snapshots include the host-configured image count budget and dimension limit. Ordinary edits preserve both fields; the plugin does not set or unset them.

The compatibility range remains `>=0.1.1-rc.2` with no upper bound. The new host verification baseline is `0.2.3-alpha.2`.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.8
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.8
```

升级后重新加载插件或重启 DSH，再刷新浏览器页面。 / Reload the plugin or restart DSH after upgrading, then refresh the browser page.
