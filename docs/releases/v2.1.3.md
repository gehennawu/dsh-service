# v2.1.3（2026-11-04）

## 新增 / 修复

- **适配 DSH 0.2.2-alpha.3**：修复失败插件重新加载在新版宿主上无法恢复的问题，保留旧宿主恢复路径；已验证宿主基线更新至该版，兼容声明仍为 `>=0.1.1-rc.2`、不设上界。
- **移动端抽屉与设置入口**：消除官方抽屉按钮和遮罩与插件补件的重复，恢复抽屉内设置入口与滑动关闭；避免抽屉被误套全屏模态或横排导航样式，修正头部让位。
- **沉浸阅读**：官方抽屉按钮随会话头部隐藏，退出沉浸时恢复，支持减少动态效果设置；旧宿主按钮保持原有行为。
- **设置导航图标**：五个分节接入官方图标槽，旧宿主保留兼容回退；修正英文模型统计导航标签与模型配置撞名。
- **模型配置**：支持请求图片张数上限与卸载步长。校验包含默认值及恢复的继承值，非法组合返回明确错误，不写入配置；补齐中英文提示。
- **插件体检**：修复等待依赖的插件被误报为缺少全部依赖的问题；仅列出可以确定缺失的服务，无法可靠判定时只显示等待状态。

## Added / Fixed

- **DSH 0.2.2-alpha.3 compatibility**: fix recovery of failed plugins on the new host while retaining the legacy recovery path. The verified host baseline moves to this version; the declared range remains `>=0.1.1-rc.2` with no upper bound.
- **Mobile drawer and settings entry**: remove duplicate drawer controls and dimming layers, restore the settings entry inside the drawer and swipe-to-close, prevent modal and horizontal-navigation styles from affecting the drawer, and correct header clearance.
- **Immersive reading**: the official drawer control now hides with the conversation header and returns when leaving immersive mode, including reduced-motion support. Legacy controls keep their existing behavior.
- **Settings navigation icons**: use the official icon slot for five sections, retaining the fallback on older hosts. Fix the English model-usage label colliding with model configuration.
- **Model configuration**: support per-request image-count limits and image-offload counts. Validate defaults and restored inherited values, reject invalid combinations before writing, and provide actionable Chinese and English errors.
- **Plugin diagnostics**: avoid reporting every dependency as missing for a pending plugin. Name only services known to be missing; report the pending state without guessing when availability cannot be established reliably.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.3
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.3
```

请使用精确版本号，避免 pnpm 发布观察期选择旧版本。宿主端修复需重新加载插件或重启 DSH；客户端更新后请刷新页面。

Use the exact version to avoid pnpm's release cooldown selecting an older release. Host-side fixes require reloading the plugin or restarting DSH; refresh the page after updating the client.

Linux + Docker: 939 tests (935 passed, 4 skipped, 0 failed; 3 skips are opt-in browser checks), plus 6/6 explicitly enabled Chromium checks. Regression coverage includes immersive hiding and restoration for official and legacy drawer controls, reduced motion, real Cordis pending fibers, and image-count defaults, inheritance, and pre-write rejection.
