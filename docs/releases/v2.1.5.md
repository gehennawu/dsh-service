# v2.1.5（2026-11-07）

## 修复

- **侧栏设置入口去重**：宿主已显示原生设置行时，插件自动让位，不再出现两行「设置」；账号按钮占用原生位置时，仍保留账号按钮上方的快捷入口，并跟随槽位声明和账号入口变化自动更新。
- **新增入口开关**：在「配置 → 功能」的交互组提供「侧栏设置入口」开关，默认开启，可立即关闭插件入口；中英说明同步补齐。
- **生命周期与稳健性**：避免无关开关变化导致入口反复重挂，隔离入口注册异常，并补齐晚声明、注销与卸载相关回归测试。

## Fixed

- **Deduplicate the sidebar Settings entry**: automatically yield when the host already displays its native Settings row. Keep the shortcut above the account button when the account launcher occupies that seat, and react to slot declarations and launcher changes.
- **Add an entry switch**: the Interaction group under Configuration → Features now includes a live “Sidebar settings entry” switch, enabled by default. Chinese and English documentation is updated.
- **Lifecycle and robustness**: avoid unnecessary remounts on unrelated feature changes, isolate entry registration errors, and expand regression coverage for late declarations, removal, and disposal.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.5
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.5
```

升级后重新加载插件或重启 DSH，并刷新浏览器页面。

Reload the plugin or restart DSH after upgrading, then refresh the browser page.
