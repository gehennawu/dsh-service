# v2.0.6（2026-10-10）

## 修复

- **大备份导入不再因 Base64 校验栈溢出而失败**：修复从 Web 端下载较大的备份并在桌面端导入时可能出现的 `Maximum call stack size exceeded`；保留文件大小、编码一致性及归档完整性检查，小备份与原有导入格式不变。
- 新增较大有效归档导入及非法 Base64 拒绝的回归测试。自动化测试在 Linux 环境通过；桌面端图形界面尚未实机验证。

## Fixed

- **Large backup imports no longer fail with a Base64-validation stack overflow**: fixes `Maximum call stack size exceeded` when importing a large backup downloaded from Web into Desktop. Size limits, canonical encoding checks, and archive integrity validation remain in place; smaller backups and the existing import format are unchanged.
- Adds regression coverage for importing a large valid archive and rejecting malformed Base64. Automated tests passed on Linux; the Desktop GUI has not yet been tested on a real installation.
