# v2.0.5（2026-10-03）

v2.0.5 适配 DSH 0.2.1-alpha.1：支持声明扩展至该版本，移动端统计条适配官方「活动 / 用量」拆分，并修复非全局安装下宿主版本读错的问题。

## 新增 / 修复

- **兼容 · 支持声明扩展至 DSH 0.2.1-alpha.1**：对 266 commits 窗口做源码级、npm 产物级（按 rolldown 区域切片的逐源模块 sha256）与隔离 profile 真机挂载审查：20 条既有接缝 17 条区域级逐字节相同、3 条均不触及本插件契约；9 个 slot key、25 个主题令牌与插件使用的 35 项官方 `data-*` 全部零丢失；官方本版移除运行时 invariant 机制（各包 `./invariant` 导出归零）本插件零引用；`engines.dsh` 上界放宽至 `<0.2.1-alpha.2`，真机挂载冒烟 12 项通过。
- **修复 · 移动端统计条适配官方「活动 / 用量」拆分**：官方把 composer 统计行拆成两个独立条目并删除行根类，原行级样式在新宿主上失效。现同时保留旧锚（老宿主）并新增官方新钩子 `[data-composer-stat]` 的同形约束与极窄屏字号阶梯（新宿主），两版视觉一致、单行零截断。
- **修复 · 宿主版本探测在非全局安装下读错**：`npx`、`npm i --prefix`、隔离 profile 等安装下，插件原先会读到机器上另一份 DSH 的版本，使版本卡与「已是最新」判定失真；现改以当前进程入口定位真正在运行的宿主，逐级回落，取不到时显示未知。
- **测试 · 重置卡用例夹具日期改用远期值**：原夹具日期已过期，文案断言随日期漂移发红，改用远期日期保持断言语义不变。

## Added / Fixed

- **Compatibility · Declared support through DSH 0.2.1-alpha.1**: a source-level, npm-artifact-level (per-source-module sha256 over rolldown regions) and isolated real-host review of the 266-commit window confirmed that 17 of the 20 existing seams are region-identical while the 3 changed ones do not touch this plugin's contracts, with zero removals across the 9 slot keys, 25 theme tokens and the 35 official `data-*` hooks this plugin uses; the removed runtime invariant mechanism (each package's `./invariant` export retired) is unreferenced here; the `engines.dsh` upper bound is widened to `<0.2.1-alpha.2` and real-host mounting smoke tests pass.
- **Fixed · Mobile stats row adapted to the official activity/usage split**: upstream split the composer stats row into two independent entries and dropped the row root class, which disabled the previous row-level rules on the new host. Both the legacy anchor (older hosts) and the official `[data-composer-stat]` hook with the narrow-screen font step (new host) are now covered, with identical single-line, untruncated layout in both.
- **Fixed · Host version detection on non-global installs**: under `npx`, `npm i --prefix`, or isolated profiles the plugin could report the version of a different DSH installation, skewing the version card and the "up to date" verdict; detection now anchors on the running process entry with staged fallbacks and reports unknown when none apply.
- **Test · Reset-card fixture moved to a far-future date**: the previous fixture date had passed, making the wording assertion drift with the calendar; a far-future date keeps the assertion semantics unchanged.
