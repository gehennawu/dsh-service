# v2.0.7（2026-10-10）

## 新增 / 修复

- **备份 · 跨设备恢复预检与目标 Profile 映射**：恢复前提示来源与当前平台/架构差异、Windows 路径长度与大小写折叠风险，以及会话目录的写入风险；归档内 Profile 可映射至本机已有 Profile 或保留原名。跨名映射默认不覆盖本机插件清单，需要时可显式选择覆盖；提交前仍执行完整性与目标状态复检。Linux 自动化测试已通过；Windows / macOS 桌面端图形恢复未实机验收。
- **额度 · 凭据入口常驻、确定性失败转手动重试**：已配置的渠道也可直接修改或清除凭据；鉴权、订阅失效、管理面不可用等确定性失败停止自动重试，保留手动重试入口与冷却提示。CLIProxyAPI 的凭据拒绝、管理面关闭及 fail2ban 封禁分别呈现，不把封禁误判为密钥错误。
- **兼容 · DSH 0.2.1-alpha.2**：子代理路由兼容新版 `startActivation` 与旧版启动入口；移动端后台任务芯片适配官方移除根类和菜单 portal 化。支持范围为 `>=0.1.1-rc.2 <0.2.1-alpha.3`，保留旧版支持；当前 alpha.2 Web 宿主上验证了真实 `subagent` / `subagent_fork` 派发，以及有运行中任务时的窄屏芯片与菜单。旧宿主真机 UI 对照、不同标签数等仍未验证。

## Added / Fixed

- **Backup · Cross-device restore preflight and target Profile mapping**: the restore preview highlights source/target platform and architecture differences, Windows path-length and case-folding risks, and session-directory write risks. Archived Profiles can map to an existing local Profile or keep the source name. Mapping to a different name preserves the local plugin package list by default; overwriting it requires an explicit choice. Integrity and target-state checks still run before applying changes. Automated tests passed on Linux; the Windows/macOS Desktop restore UI has not been tested on a real installation.
- **Quota · Persistent credential controls and manual retry for deterministic failures**: credentials can now be replaced or cleared even on configured providers. Authentication, expired subscription, disabled management API, and similar deterministic failures pause automatic retries while keeping a manual retry action and cooldown guidance. CLIProxyAPI distinguishes rejected credentials, disabled management, and fail2ban bans.
- **Compatibility · DSH 0.2.1-alpha.2**: subagent routing supports the new `startActivation` API and legacy startup methods; mobile background-job controls adapt to the removed root class and portaled menu. The supported range is `>=0.1.1-rc.2 <0.2.1-alpha.3`, retaining older hosts. Real `subagent` / `subagent_fork` dispatches and narrow-screen job-chip/menu behavior with a running task were verified on the current alpha.2 Web host. A real older-host UI comparison and other tab counts remain unverified.
