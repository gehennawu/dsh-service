# v2.1.0（2026-10-19）

## 新增 / 修复

- **额度查询接入 WorkBuddy2API 面板用量**（新类型「workbuddy2api panel 用量」，仅手动适配，只对接 `workbuddy2api-panel` 项目的 `/panel/api/*` 接口）：区域（cn / global）按每日模型量画油表（默认分母 200M / 100M tokens，超上限时百分比截 100 但保留真实用量）；账号行给出请求 / Token / **剩余积分**（余额台账缺失时回落本窗口消耗）；**限流台账**按区域列出被限流模型与上游重置时间、账号级冷却的恢复时刻（无锁显示「限流状态 —」，接口不可用时静默降级）；对话圆环按当前模型的 `cn:` / `global:` 前缀读对应区域油表。油表分母可在 quota 配置的 `realmCaps` 覆盖（编辑入口暂不展示）。
- **侧栏常驻设置入口**：账号按钮正上方常驻「设置」行，点击直接打开官方设置面板，已登录/未登录都显示；折叠成图标条时为齿轮钮。
- **模型配置：最大输出 token 的建议与语义修正**：模型编辑页按上下文窗口给出可解释的建议值并显示填入后约多少 tokens 触发压缩；明确 maxTokens 是单次请求输出预留而非能力上限，智能填充里的能力上限改为只读、不再自动填入；编辑页给出压缩阈值估算与越界红字警告。
- **智能填充识别带前缀与变体的模型 ID**：`cn:` 前缀、中转前缀、`:free` 变体、`-high` 思考档都能命中固定资料；精确 ID 永远优先，别名只作身份参考，不生成 wire/compat。
- **新建渠道候选模型清单支持搜索**：候选数量 >5 时出现本地搜索（按 ID 与名称过滤），全选只作用于过滤后的可见项。
- **兼容基线推进**：README「已验证至」更新为 DSH `0.2.1-alpha.5`；`engines.dsh` 仍是开区间 `>=0.1.1-rc.2`（不设上界）。

## npm 安装 / Install from npm

在 DSH 插件管理页输入：

```text
@gehennawu/dsh-service@2.1.0
```

或使用命令行（将 `web` 换成你的 Profile 名）：

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.0
```

精确版本号可避免 pnpm 发布观察期自动回退到旧版本；新发布版本仍可能包含尚未发现的问题。

## Added / Fixed

- **Quota lookup now supports the WorkBuddy2API panel** (new manual-adaptation type “workbuddy2api panel usage”, targeting the `/panel/api/*` endpoints of the `workbuddy2api-panel` project only): per-realm (cn / global) daily-volume gauges (default caps 200M / 100M tokens; the percentage clamps at 100 while the real figure stays visible); account rows show requests / tokens / **credits left** (falling back to the window's consumed credits when the balance ledger is unavailable); a **rate-limit ledger** lists limited models with their upstream reset time and account-level cooldown recovery times (it reads “Rate limits —” when nothing is limited and degrades silently when the endpoint is missing); the composer ring follows the selected model's `cn:` / `global:` prefix. Gauge denominators can be overridden through `realmCaps` in the quota config (the editor entry is not shown for now).
- **Persistent settings entry in the sidebar**: an always-visible “Settings” row right above the account button opens the official settings panel; it shows whether or not you are signed in, and becomes a gear icon in the collapsed rail.
- **Model config: max-output-token advice and a corrected meaning**: the model editor suggests a value derived from the context window and shows how many tokens would trigger compaction after filling it in; maxTokens is a per-request output reservation, not the model's capability ceiling — the smart-fill capability ceiling is now read-only and never auto-filled; the editor shows the compaction-threshold estimate plus a red warning when out of bounds.
- **Smart fill recognizes prefixed and variant model IDs**: `cn:` prefixes, relay prefixes, `:free` variants and `-high` effort suffixes now resolve to the fixed dataset; exact IDs always win and aliases only serve as identity hints, never producing wire/compat settings.
- **Search in the new-channel candidate model list**: with more than five candidates a local search (by ID and name) appears, and “select all” only applies to the filtered visible items.
- **Compatibility baseline advanced**: the README “verified through” note now reads DSH `0.2.1-alpha.5`; `engines.dsh` remains the open range `>=0.1.1-rc.2` (no upper bound).
