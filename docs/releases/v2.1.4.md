# v2.1.4（2026-11-05）

## 新增 / 修复

- **信息架构与导航**：健康诊断移入「维护」聚合页作为首位子页（健康诊断 · 会话管理 · 技能 · 备份维护 · 重启）；顶层主标签收敛为六页单行（概览 · 模型统计 · 额度查询 · 模型配置 · 维护 · 配置）。
- **告警与操作**：健康诊断异常向外聚合至维护主标签 ⚠ 与顶部服务控制提醒，子页内保留独立 ⚠ 标注；维护页头在健康诊断激活时展示「立即健康检查 / 重新诊断」操作。
- **移动端体验**：消除移动端进入沉浸模式时抽屉图标的切换抖动，修复长模型名称在模型选择按钮上收展引起的布局振荡。
- **DSH 兼容基线**：记录 DSH 0.2.2-rc.1 已验证基线，兼容声明保持开区间 `>=0.1.1-rc.2`、不设上界。

## Added / Fixed

- **Information architecture & navigation**: move Health diagnostics into the Maintenance aggregate page as the first subpage (Health diagnostics · Sessions · Skills · Backups · Restart); consolidate primary navigation into six single-line tabs (Overview · Model stats · Quota lookup · Model configuration · Maintenance · Configuration).
- **Alerts & actions**: aggregate Health diagnostics issues to the primary Maintenance tab ⚠ and top alert banner while retaining sub-tab ⚠ dots; show the "Run health check / Re-check" action in the Maintenance page header when the diagnostics subpage is active.
- **Mobile experience**: eliminate drawer-icon transition jitter when entering immersion mode on mobile, and prevent layout oscillation caused by collapsing/expanding long model names on the model selection button.
- **DSH compatibility baseline**: document the verified baseline for DSH 0.2.2-rc.1; declared range remains `>=0.1.1-rc.2` with no upper bound.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.4
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.4
```

请使用精确版本号，避免 pnpm 发布观察期选择旧版本。宿主端修复需重新加载插件或重启 DSH；客户端更新后请刷新页面。

Use the exact version to avoid pnpm's release cooldown selecting an older release. Host-side fixes require reloading the plugin or restarting DSH; refresh the page after updating the client.
