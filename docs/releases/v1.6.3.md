# v1.6.3（2026-09-16）

v1.6.3 是一批会话管理与概览收敛：派发给子代理的会话现在可以被识别、筛选并一键并入批量选择，概览页则去掉了一排与功能页重复的快捷入口。

## 新增 / 修复

- **子代理会话识别、筛选与批量勾选**：会话列表为子代理派发的会话加「子代理」徽章，判据取自官方会话头——`origin=subagent` 为产品分类，老日志缺该字段时以 `delegationDepth>0` 兜底，仅带 `parentSession` 的 fork 血统不算子代理；搜索行新增「仅子代理」复选框（与「仅搜归档」同行同款控件，叠加在 全部 / 仅归档 之上，已删除视图隐藏，切换视图保留状态），批量模式新增「选中子代理」，把当前可见的子代理会话并入选择集（不清空已有选择，可见行中没有子代理时按钮隐藏），便于成批归档或删除。
- **修复 · 概览页移除重复的核心操作入口**：健康检查、额度查询、创建备份三个快捷按钮在各自功能页内都有常驻入口，概览页不再重复摆放；概览回到「状态摘要 → 可行动项 → 版本与运行环境 → 指标格 → 近期报错」分段。

## 兼容性与升级提示

- 子代理标志由宿主加性下发：旧客户端忽略新字段，新客户端在旧宿主上自动回落为无标志的原有行为；勾选「仅子代理」而列表未携带任何标志时会提示宿主较旧、升级重启后生效，不再给出无解释的空列表。
- 从 1.6.2 升级无需修改任何配置；对 DSH 的适配范围与 1.6.2 相同（`0.1.1-rc.2` 至 `0.1.6-alpha.1`，后者已真机验收）。
- 本版本通过 389 项自动化测试。

## Added / Fixed

- **Subagent session recognition, filtering, and batch selection**: the session list now badges sessions delegated to subagents — the marker comes from the official session header, where `origin=subagent` is the product classification, `delegationDepth>0` is the fallback for older logs, and a plain fork lineage carrying only `parentSession` does not count; the search row gains a "Subagents only" checkbox (same row and widget language as "search archived only", layered on top of All / Archived, hidden in the Deleted view, and its state survives view switches), and batch mode gains "Select subagents", which folds every visible subagent session into the selection (existing picks are kept; the button stays hidden when no visible row is a subagent) for quick batch archive or delete.
- **Fixed · removed duplicate core-action entries from the overview**: the Health check, Quota lookup, and Create backup shortcuts all have permanent entries inside their own feature pages, so the overview no longer repeats them; the overview returns to "status summary → actionable items → version and runtime → metrics grid → recent errors".

## Compatibility and upgrade notes

- The subagent flag is shipped additively by the host: older clients ignore the new field, and newer clients fall back to the previous flagless behaviour on older hosts; enabling "Subagents only" while the list carries no flag explains that the host is outdated and that an upgrade plus restart is needed, instead of showing an unexplained empty list.
- Upgrading from 1.6.2 requires no configuration change; the DSH range is unchanged from 1.6.2 (`0.1.1-rc.2` through `0.1.6-alpha.1`, the latter verified on a real deployment).
- This release passes all 389 automated tests.
