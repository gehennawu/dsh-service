# v2.0.8（2026-10-13）

## 新增 / 修复

- **模型配置独立页**：供应商按纵向手风琴展示，支持连接信息、密钥、模型添加/删除、可编辑模型 ID、名称和容量配置。模型列表显示名称，悬停查看 ID；输入/输出模态并排，思考等级使用六档等宽横排，选中后不改变宽度。文本输入始终勾选并锁定。
- **按模型智能填充**：查询本机 pi-ai 和固定 OpenRouter / modelparams 资料，不以当前渠道筛选。统一展示建议，一键填入经二次确认后只更新草稿，仍需保存；缺少建议或仅声明支持思考但没有档位时分别提示，不猜测缺失值。开关悬停可查看资料来源与功能边界。
- **渠道与模型启停及删除守卫**：停用策略按 Profile 保存，过滤模型目录并拒绝新调用，保留配置和密钥。删除确认列出主对话及子代理主模型/回退模型的具体引用；有冲突则禁止删除。模型改名拒绝重复 ID、受引用条目和已停用模型，内置渠道增改模型不写死目录连接默认值。
- **Anthropic 模型发现与基础测试**：补充安全的 Anthropic 模型列表获取，沿用 HTTPS、公网 DNS、响应大小与超时护栏。模型行可主动测试已保存配置，显示耗时和脱敏失败信息；上限 30,000 token / 120 秒，可能计费，仅验证基础文本调用。
- **统计与安装说明**：统计页挂载时补拉，并在实际数据变化边沿同步；安装示例使用精确版本号，说明 pnpm 发布观察期行为。

## npm 安装 / Install from npm

在 DSH 插件管理页输入：

```text
@gehennawu/dsh-service@2.0.8
```

或使用命令行（将 `web` 换成你的 Profile 名）：

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.0.8
```

精确版本号可避免 pnpm 发布观察期自动回退到旧版本；新发布版本仍可能包含尚未发现的问题。

## Added / Fixed

- **Dedicated model configuration page**: providers use a vertical accordion with connection/credential editing, model add/delete, editable model IDs, names and capacities. Rows show names with IDs on hover. Input/output modalities share a row; six equal-width reasoning controls stay horizontal without resizing when checked. Text input remains checked and locked.
- **Model-based smart fill**: looks up local pi-ai and fixed OpenRouter / modelparams metadata without filtering by the current provider. Fill all requires one confirmation and only updates the draft; Save is still required. Missing suggestions and reasoning support without declared levels have distinct notices; missing values are never fabricated. Hovering the switch explains sources and boundaries.
- **Provider/model availability and deletion guards**: Profile-scoped disable policies filter catalogs and reject new calls while retaining configuration and credentials. Delete confirmations list exact main-chat and subagent primary/fallback references and block conflicts. Renames reject duplicate IDs, referenced models and disabled models; built-in model edits do not pin catalog connection defaults.
- **Anthropic discovery and basic call tests**: safe Anthropic model-list discovery retains HTTPS, public-DNS, response-size and timeout guards. Row actions can test saved entries with elapsed time and sanitized failures. The ceiling is 30,000 tokens / 120 seconds and may incur charges; only a basic text call is verified.
- **Usage refresh and installation guidance**: usage refreshes on mount and actual change edges. Installation examples pin exact versions and explain pnpm release cooldown behavior.

Enter `@gehennawu/dsh-service@2.0.8` in DSH’s plugin manager, or run the command above with your Profile name. Pinning avoids automatic fallback during pnpm’s release cooldown; newly published versions may still contain undiscovered issues.

## 验证范围 / Verification scope

Linux + Docker 自动化回归与现有 Web GUI 的隔离浏览器验证。未因此发布执行真实模型推理或修改用户 Profile；基础测试不代表全部接口能力已验证。模型配置写入要求宿主提供可追踪的配置 revision。

Automated Linux + Docker regressions and isolated browser checks in the existing Web GUI. No real inference or user Profile writes were performed for this release. Basic tests do not establish every API capability. Model-configuration writes require trackable host configuration revisions.
