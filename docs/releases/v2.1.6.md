# v2.1.6（2026-11-12）

## 适配 DSH 0.2.2-rc.2

- **子代理参数兼容**：DSH 0.2.2-rc.2 把子代理启动参数从嵌套改成顶层。插件现在按实际传入形态选择，全局子代理路由、思考等级与独立预设重新生效，输入框下方的子代理记录也会恢复；旧版宿主的嵌套参数与更早的双入口继续可用。
- **归档前先看后果**：归档改为「宿主生成一次性后果清单 → 确认执行」，单项与批量一致；旧的直接归档调用会被拒绝，无法绕过确认。清单会尽力显示该会话记录过的工作树候选，并说明分支与提交保留、未跟踪改动不构成保留保证、取消归档不恢复已删除目录。归档结果与后台清理状态分别展示，可手动刷新；未知状态不会被当成「已保留」。
- **支持 Gemini 原生协议**：宿主声明支持时，「模型配置 → 添加渠道」可选用 Gemini 原生协议，需要 API Key，地址保留服务版本路径（如 `/v1beta`）。在线获取模型使用官方接口与鉴权，只读第一页（最多 1000 个），其余可手填；不会发起生成请求。思考等级只提供该协议支持的 minimal / low / medium / high 四档，既有非标准配置不会因无关编辑被自动改写。
- **兼容声明**：`engines.dsh` 仍为开区间 `>=0.1.1-rc.2`，已验证基线为 `0.2.2-rc.2`。宿主不支持某协议时该选项不出现，草稿保留。

## 移动端

- **后台任务与子代理芯片改用官方图标**：胶囊直接采用宿主自带的层叠图标与人形图标，不再和官方图标叠画；数字在首屏即可显示，不必等滚动后才出现。
- **会话标题显示更完整**：移动端标题字号收紧并回收了一处被重复扣减的左侧让位，390px 宽下可见字符增加约 18%，标签行位置与官方保持一致。

## 已知边界

- 子代理派发记录保存在宿主内存中，重启 DSH 后清空；新派生会重新累积。
- 归档引发的后台清理资格由宿主在异步阶段判定，插件只做条件提示，不承诺目录一定保留。
- 本轮未对真实渠道写入、计费调用或删除性清理做现场验收。

## Fixed

- **Subagent argument compatibility**: DSH 0.2.2-rc.2 moved subagent start arguments out of a nested object. The plugin now adapts to the shape actually passed, so the global subagent route, reasoning effort, and independent presets take effect again, and the subagent line under the composer returns. Nested arguments on older hosts and the even older dual entry points keep working.
- **Archive consequences come first**: archiving is now “host issues a single-use consequence plan, then you confirm”, identical for single and batch operations; the old direct call is rejected so the confirmation cannot be bypassed. The plan shows any worktree candidate recorded for the session and states that branches and commits are kept, untracked changes are not a retention guarantee, and unarchiving does not restore a removed directory. Archive outcome and background cleanup are reported separately and can be refreshed manually; unknown is never presented as retained.
- **Native Gemini protocol**: when the host declares support, “Models → Add provider” offers the native Gemini protocol. It requires an API key and keeps the API version in the base URL (for example `/v1beta`). Model discovery uses the official endpoint and authentication, reads only the first page (up to 1,000 entries), and leaves the rest to manual entry; no generation request is sent. Reasoning offers only the four values the protocol supports (minimal / low / medium / high), and existing nonstandard configuration is never rewritten by an unrelated edit.
- **Compatibility**: `engines.dsh` stays an open range `>=0.1.1-rc.2`, with `0.2.2-rc.2` as the verified baseline. When the host does not support a protocol, the option is hidden and your draft is kept.

## Mobile

- **Background-task and subagent chips use the official icons**: the pills adopt the host's own layers and users icons instead of drawing on top of them, and the count appears on first paint rather than only after scrolling.
- **Longer session titles on phones**: the title font is tightened for mobile and a duplicated left inset is reclaimed, showing about 18% more characters at 390px while the tab row keeps its official position.

## Known limits

- Subagent dispatch records live in host memory and are cleared when DSH restarts; new delegations accumulate again.
- Whether an archive actually removes a worktree is decided by the host in its asynchronous stage. The plugin gives conditional guidance and does not promise retention.
- This round did not verify real provider writes, billed calls, or destructive cleanup on a live instance.

## npm 安装 / Install from npm

在插件管理页输入 / Enter in the plugin manager:

```text
@gehennawu/dsh-service@2.1.6
```

或使用命令行，将 `web` 换成实际 Profile 名 / Or use the CLI, replacing `web` with your profile name:

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.6
```

升级后重新加载插件或重启 DSH，并刷新浏览器页面。

Reload the plugin or restart DSH after upgrading, then refresh the browser page.
