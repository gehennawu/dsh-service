# v1.7.0（2026-09-17）

v1.7.0 是一批配置与额度侧的扩展：设置页左侧标签支持手动排序与显隐并跨设备同步，技能列表长列表默认折叠当索引用，额度查询补上 Command Code（command-goat）渠道。

## 新增 / 修复

- **设置栏左侧标签手动排序与显隐管理**：新增「服务控制 → 配置 → 设置栏标签」管理页，可拖拽或上下箭头调整设置页左侧标签顺序、逐个显隐，并一键恢复默认；`dsh-service` 自身条目永久锁定，排序模式下无法把自己隐藏掉。
- **统一配置文件与设置栏配置多端同步**：轻量偏好收敛到单一 `$DSH_HOME/dsh-service-config.json`（原子写入 0600、128KB 上限，按区块读改写，改一个功能块不影响其他块）；设置页标签配置写入后端权威事实源，换浏览器、无痕模式或多台设备登录同一部署时自动带回，后端为空且本地有历史配置时自动迁移一次；拉取失败会在下次打开面板时重试，写后端失败会在下次打开时重推本地已生效配置。
- **技能列表默认折叠**：技能条目折叠为「箭头 + 名称 + 来源徽标」一行，描述、用法与开关收进折叠体，点头部行单条开合；列表顶部新增「全部展开 / 全部折叠」（作用域为名称过滤后的可见条目）。无效条目的 ⚠ 提示与一键修复留在折叠体外，折叠态照常可见。
- **新增 · Command Code（command-goat）渠道额度查询**：额度页可直接适配 `command-goat` 渠道，读取官方账号额度——账户余额、本周期已用、订阅套餐（含到期倒计时）与 5 小时 / 每周用量窗口；额度面与推理面共用同一把 key，无需另配凭据，卡片保留官网用量页外链。
- **修复 · 业务信封错误码定族**：上游把「凭据被拒 / 套餐失效 / 服务自身故障」都塞进 HTTP 200 的业务信封时，不再一律报成「响应格式异常」——鉴权失败判凭据被拒并保留填写入口，套餐到期判无生效订阅，上游自身故障判「上游服务故障」（后者不再让渠道从子代理路由里被摘掉）。
- **修复 · 显式 baseURL 渠道的用量端点归一**：修掉 OpenCode Go 的 anthropic-messages 组渠道（`…/zen/go`）打到不存在的 `/usage` 路径返回 404 网页的问题；同域带 `/v1` 的那条路径才是用量端点。另外，免费 / 未充值 key 的零额度不再被误报成「响应格式异常」，改为显示可读的 `$0.00` 余额。
- **修复 · 设置栏标签单语显示与窄屏截断**：标签在导航条、管理页与 DOM 映射中统一按当前界面语言显示单侧文案（此前「中文 / English」双语并排）；窄屏下标签不再被 ID 与锁定徽标挤压变形。
- **修复 · 设置栏同步与槽位生命周期**：修正设置栏配置同步与槽位注册 / 注销的生命周期问题，避免条目残留或丢失。
- **修复 · Command Code 窗口绝对数补币种符号**：5 小时 / 每周窗口的绝对数改为带 `$` 的金额（如 `7% · $1.03 / $14.00`），此前按 token 数量缩写渲染，缺了币种符号。
- **修复 · 正圆与胶囊被外壳压成方角**：适配外壳的 `corner-shape` 规则，插件自有的圆点、胶囊按钮、进度条、开关轨道恢复正圆与胶囊几何。

## 兼容性与升级提示

- 设置栏标签配置首次写入后端统一配置文件时自动迁移一次，无需手工操作；配置文件缺失或损坏时回退到浏览器本地配置，不阻塞界面。
- Command Code 额度为纯新增适配：未适配的供应商绝不发起请求，旧配置无需改动。
- 从 1.6.3 升级无需修改任何配置；对 DSH 的适配范围与 1.6.3 相同（`0.1.1-rc.2` 至 `0.1.6-alpha.1`）。
- 本版本通过 412 项自动化测试。

## Added / Fixed

- **Manual ordering and visibility for settings sidebar labels**: a new "Service control → Configuration → Sidebar labels" page lets you drag or arrow-move the settings sidebar labels, hide individual entries, and restore defaults in one click; the `dsh-service` entry itself stays locked so ordering mode cannot hide it.
- **Unified config file and cross-device sync for sidebar settings**: lightweight preferences converge into a single `$DSH_HOME/dsh-service-config.json` (atomic writes at 0600, 128 KB cap, per-section read-modify-write so editing one feature block never touches another); sidebar layout is written to an authoritative backend and comes back automatically on another browser, in private mode, or on another device signed into the same deployment, with a one-time migration when the backend is empty and local history exists; failed reads retry on the next panel open and failed backend writes re-push locally applied config the same way.
- **Skills list collapses by default**: each skill entry folds into a single "arrow + name + source badge" row with description, usage, and toggles inside the collapsed body, and clicking the header row toggles that entry alone; a new "Expand all / Collapse all" button at the top of the list scopes to the entries visible after name filtering. Invalid entries keep their ⚠ notice and one-click fix outside the collapsed body.
- **Added · Command Code (command-goat) quota lookup**: the quota page can now adapt the `command-goat` channel and read its official account quota — account balance, period spend, subscription plan (with renewal countdown), and the 5-hour / weekly usage windows; the quota plane reuses the inference key with no extra credential, and the card keeps its link to the official usage page.
- **Fixed · business-envelope error codes classified by meaning**: when the upstream stuffs "credential rejected / plan expired / vendor-side failure" into an HTTP 200 business envelope, it is no longer reported as "unexpected response format" across the board — an auth failure reads as credential rejected and keeps the credential form, an expired plan reads as no active subscription, and a vendor-side failure reads as an upstream service error (which no longer removes the channel from subagent routing).
- **Fixed · usage endpoint normalization for channels with an explicit baseURL**: fixes OpenCode Go's anthropic-messages channel (`…/zen/go`) hitting a nonexistent `/usage` path and returning a 404 web page; the `/v1` variant on the same host is the real usage endpoint. Separately, a free or unfunded key's zero balance is no longer misreported as "unexpected response format" and shows a readable `$0.00` instead.
- **Fixed · sidebar labels show one language and no longer truncate on narrow screens**: labels now render single-language across the nav bar, management page, and DOM mapping (previously bilingual "中文 / English" side by side), and narrow screens no longer squeeze them against IDs and lock badges.
- **Fixed · sidebar sync and slot lifecycle**: corrects the lifecycle of sidebar config sync and slot registration/teardown so entries neither linger nor disappear.
- **Fixed · Command Code window figures carry a currency symbol**: the 5-hour and weekly windows now render amounts with `$` (e.g. `7% · $1.03 / $14.00`); they previously used token-count abbreviation and dropped the currency marker.
- **Fixed · circles and pills flattened by the shell**: adapts to the shell's `corner-shape` rules so plugin-owned dots, pill buttons, progress bars, and switch tracks keep true round and pill geometry.

## Compatibility and upgrade notes

- Sidebar label config migrates into the backend unified config file once, automatically; when that file is missing or corrupt, the browser's local config is used as a fallback and the UI is never blocked.
- Command Code quota is a purely additive adaptation: unadapted providers are never requested, and existing config needs no change.
- Upgrading from 1.6.3 requires no configuration change; the DSH range is unchanged from 1.6.3 (`0.1.1-rc.2` through `0.1.6-alpha.1`).
- This release passes all 412 automated tests.
