# v2.1.1（2026-10-24）

## 修复与改进

- **恢复 CPA 的 Gemini 五小时／本周额度**：更新 Antigravity 查询的客户端身份，修复上游对旧版本仅返回 Claude/GPT 分组的问题。Gemini 继续显示独立的「5 小时」「本周」额度与各自重置时间，不展开成模型列表，也不合并成单条额度。
- **修复 DSH 最新版本检查失败**：优先读取 npm dist-tags，避免完整版本元数据超过响应上限而显示「暂时无法检查最新版本」。
- **移动端计数芯片避让更多视图按钮**：任务与子代理数量改为图标加数字胶囊，修正裁字、遮挡与间距，运行中的图标和胶囊底色联动闪烁，并遵循减少动态效果设置。
- **会话管理交互优化**：改进列表、搜索、分组、批量操作和详情展示。
- **备份维护界面优化**：调整页面布局、操作工具栏与归档列表，统一创建和导入按钮的尺寸及样式。
- **移除 WorkBuddy2API 面板余额适配**：撤下余额查询实现及手动类型选项；不修改已有推理配置和凭据，保留渠道图标。
- **兼容性验证基线**：已验证至 DSH `0.2.1-rc.3`；兼容声明继续保持 `>=0.1.1-rc.2`，不设上界。

## npm 安装 / Install from npm

在 DSH 插件管理页输入 / Enter in the DSH plugin manager:

```text
@gehennawu/dsh-service@2.1.1
```

或使用命令行（将 `web` 换成实际 Profile 名）/ Or use the CLI (replace `web` with your profile name):

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.1
```

请使用精确版本号，避免 pnpm 发布观察期选择旧版本。宿主半查询逻辑需重新加载插件或重启 DSH 后生效；前端界面更新后请刷新页面。

Use the exact version to avoid pnpm's release cooldown selecting an older release. Host-side query changes require reloading the plugin or restarting DSH; refresh the page after updating the frontend.

## Fixed / Improved

- **Restore CPA Gemini five-hour and weekly quotas**: update the Antigravity query's client identity so upstream no longer omits Gemini for the older client version. Gemini retains separate five-hour and weekly limits with their own reset times, rather than a model list or a single merged quota.
- **Fix failed DSH update checks**: query npm dist-tags first, avoiding oversized full package metadata that previously caused the latest-version check to fail.
- **Keep mobile activity counters clear of the More Views button**: task and subagent counters use icon-and-number capsules; fix clipped text, overlap and spacing, synchronize running icon/capsule animations, and respect reduced-motion preferences.
- **Improve session management**: refine lists, search, grouping, batch actions and details.
- **Refine backup maintenance**: improve page layout, the action toolbar and archive list, and align the sizing and styling of create/import controls.
- **Remove WorkBuddy2API panel quota support**: remove its quota implementation and manual adapter option without modifying existing inference settings or credentials; retain the provider icon.
- **Compatibility verification baseline**: verified through DSH `0.2.1-rc.3`; the declared range remains `>=0.1.1-rc.2`, with no upper bound.

## 验证范围 / Verification scope

Linux + Docker：全量 `npm test`；发布包清单核验。CPA Gemini 经同账号、同 daily 接口、同请求体的 User-Agent 单变量 A/B 和修复后真实查询验证，确认返回独立五小时与周窗口。本次发布流程未重载运行中的服务。

Linux + Docker: full `npm test` regressions and package-content checks. CPA Gemini was verified through a same-account, same-daily-endpoint, same-body User-Agent A/B test and a live query using the repaired adapter, confirming independent five-hour and weekly windows. The release process does not reload the running service.
