# v1.8.0（2026-09-18）

v1.8.0 的主题是**模型厂家图标**：输入框的模型按钮开始显示当前渠道的厂家 / 渠道品牌图标，覆盖 62 张图形、76 条渠道映射，并配一页可离线打开的图标目录。同批还带上额度卡排序改造、DSH 0.1.6-alpha.2 兼容适配与若干修复。

## 新增 / 修复

- **新增 · 输入框模型按钮显示厂家 / 渠道图标**：宽屏（>480px）加在模型名前面，手机上替换官方那枚通用图标；识别不到的渠道保持官方默认图标不变，不会出现空缺或错图。覆盖 pi-ai 内置 40 个 provider 中的 38 个，并补充 Ollama、vLLM、LM Studio、Perplexity、Cohere、火山引擎、豆包、混元、元宝、阶跃、商汤、百川、零一万物、Fal、Replicate、Midjourney 等常用渠道；自定义渠道名按前缀 / 别名自动识别（`opencode-goo` → opencode、`zai-coding-cn` → 智谱、`command-goat` → Command Code 等）。图标在构建期内联进客户端产物，**零运行期网络请求**，离线可用、不影响 CSP，也不向第三方暴露渠道名称。
- **新增 · 浅色 / 深色自动分档**：品牌色只有对浅底与深底两侧对比度都达标才保留原色，否则自动改用跟随主题文字色的单色版——不会出现深色模式下黑图标糊在黑底上、或浅色模式下近乎隐形。
- **新增 · 可离线浏览的图标目录页**：一页看全 62 张图形、76 条渠道映射、匹配规则与深浅色对照，零依赖单文件、离线可开，与内联进客户端的数据同源生成。
- **新增 · CLIProxyAPI（CPA）手绘标与按需显示**：手绘「内凹菱形 + 镜像漩涡」品牌标，**只在余额查询里把某个渠道手动适配成 CLIProxyAPI 后**才显示（渠道名不限，叫 `cpa` 还是自定义名都一样）；撤销适配立即回落官方默认图标，无需刷新页面。
- **新增 · 额度查询渠道卡片带厂家图标**：已适配卡片的渠道名前显示同一套小图标（彩色档原样上品牌色、单色档跟随主题文字色），与对话框同受「模型厂家图标」开关管辖。
- **改造 · 额度卡排序与显隐改为设置栏标签同款**：额度页的排序 / 显隐管理与设置栏标签统一到同一套交互与多端同步；支持拖拽与 ↑↓ 换位、逐卡显隐、恢复默认与保存。隐藏只影响展示，不影响查询轮询与手动适配候选区。
- **修复 · 宿主命令 `/restart` 后页面自动刷新**：对话里敲 `/restart` 与设置页「重启」按钮是两条独立入口，此前只有后者会让页面自动恢复，命令路径下页面停在断线态。现在改为按进程身份基线判定，两条入口都会自动刷新；同一进程内的断线重连不会误刷新。
- **修复 · 子代理页进入时的跳变**：进入「维护 → 子代理」时模式高亮与整块表单会先从「初始」跳到真实模式（面板高度从 287px 撑到 937px）。新增首帧缓存，进入即直落真实模式；无缓存时显示「读取配置…」，结构化响应仍是唯一事实源。
- **修复 · 设置栏标签的语言归一与管理页行布局回退**：撤销上一批对设置栏标签的单语归一与行内布局调整，标签恢复按注册原样显示、恢复原有收缩行为。
- **修复 · 图标显示门与开关一致性**：额度卡片图标此前未接入「模型厂家图标」开关（关闭后卡片图标仍显示），现与对话框一同全量摘除；同时收敛 CPA 显示门判定，并让图标目录页的图形生成与运行期保持逐字节一致。

## 兼容性与升级提示

- **DSH 适配口径上移至 `0.1.6-alpha.2`**：适配新插件管理页、设置页插件配置迁移与客户端 Session 多实例架构等契约；旧版 DSH（`>=0.1.1-rc.2`）保持兼容，新旧两套 seam 按运行时能力探测双形态走。版本卡常驻显示「适配 DSH 0.1.1-rc.2 ~ 0.1.6-alpha.2」，越界运行版本（`≥0.1.6-alpha.3`）标红警示。
- 注意：升级后以 V3 格式写入的会话日志无法被旧版 DSH 读取——**备份不可跨版本降级恢复**。
- 厂家图标为纯新增能力：默认开启，可在 插件 → 插件配置 → 交互 关闭；关闭后对话框与额度卡片的图标一并摘除，官方默认图标照旧。
- 额度卡的排序与显隐配置首次写入后端统一配置文件时自动迁移一次，无需手工操作。
- 本版本通过 426 项自动化测试。

## Added / Fixed

- **Added · Composer model button shows the provider / channel brand icon**: prepended to the model name on wide screens (>480px) and replacing the official generic icon on phones; channels with no matching mark keep the official default icon untouched, so you never get a blank or a wrong logo. Covers 38 of pi-ai's 40 built-in providers plus commonly used routes such as Ollama, vLLM, LM Studio, Perplexity, Cohere, Volcengine, Doubao, Hunyuan, Yuanbao, StepFun, SenseNova, Baichuan, 01.AI, Fal, Replicate, and Midjourney; custom route names are recognised by prefix / alias (`opencode-goo` → opencode, `zai-coding-cn` → Zhipu, `command-goat` → Command Code). Icons are inlined into the client bundle at build time — **zero runtime network requests**, works offline, needs no CSP exceptions, and never leaks your provider names to a third party.
- **Added · Automatic light / dark tiering**: a brand colour is kept only when its contrast is adequate against **both** a light and a dark background; otherwise the icon switches to a monochrome variant that follows the theme's text colour — so you never get a black logo on a dark background or a nearly invisible one in light mode.
- **Added · Offline icon catalog page**: browse all 62 marks, 76 provider mappings, the matching rules, and a light/dark comparison in a single dependency-free file that opens offline, generated from the very data inlined into the client bundle.
- **Added · Hand-drawn CLIProxyAPI (CPA) mark, shown on demand**: a hand-drawn "concave diamond + mirrored swirl" mark appears **only after you manually adapt a channel as CLIProxyAPI in the quota page** (regardless of the channel's name — `cpa` or a custom one alike); un-adapting falls back to the official default icon immediately, with no page reload.
- **Added · Quota cards carry the provider icons**: adapted cards show the same small mark before the channel name (colour tiers keep their brand colour, mono tiers follow the theme text colour), governed by the same "Model provider icons" switch as the composer.
- **Changed · Quota card ordering and visibility now match the sidebar-label pattern**: the quota page's ordering / visibility management shares one interaction model and cross-device sync with the settings sidebar labels, with drag or arrow reordering, per-card visibility, and restore-defaults; hiding affects display only and never stops polling or the manual-adaptation candidate list.
- **Fixed · the page now auto-refreshes after the host `/restart` command**: typing `/restart` in a conversation and pressing the settings "Restart" button are two independent entries, but only the latter used to bring the page back, leaving the command path stuck offline. The check now rides a process-identity baseline, so both entries recover automatically while a same-process reconnect never triggers a spurious reload.
- **Fixed · jump when entering the subagent page**: entering "Maintenance → Subagent" used to flash the mode highlight and the whole form from "initial" to the real mode (growing the panel from 287px to 937px). A first-paint cache now lands on the real mode immediately; without a cache it shows "reading configuration…", and the structured response remains the single source of truth.
- **Fixed · reverted sidebar-label language normalisation and management-page row layout**: undoes the previous release's single-language normalisation and inline layout tweaks for sidebar labels, restoring labels as registered and the original shrinking behaviour.
- **Fixed · icon display gate and feature-switch consistency**: quota-card icons were not wired to the "Model provider icons" switch (they stayed visible when it was off) and are now removed together with the composer icon; the CPA display gate was also consolidated, and the catalog page's mark generation is now byte-identical to the runtime.

## Compatibility and upgrade notes

- **DSH compatibility statement moved up to `0.1.6-alpha.2`**: adapts to the new Plugins page, the settings plugin-config migration, and the multi-instance client Session architecture; older DSH releases (`>=0.1.1-rc.2`) remain supported, with both seam shapes detected from runtime capabilities. The version card shows a standing notice "Adapted for DSH 0.1.1-rc.2 ~ 0.1.6-alpha.2", and turns red when running on unverified releases (`≥0.1.6-alpha.3`).
- Note: sessions written in the V3 format after upgrading cannot be read by older DSH releases — **backups do not restore across a version downgrade**.
- Provider icons are purely additive: on by default and switchable under Plugins → Plugin configuration → Interaction; turning it off removes the icons from both the composer and the quota cards, leaving the official default icons untouched.
- Quota card ordering and visibility migrate into the backend unified config file once, automatically.
- This release passes 426 automated tests.
