# v2.1.2（2026-10-28）

## 新增 / 修复

- **子代理路由改为派发前选路**：按额度健康与候选优先级在派发前挑选路由；新增最近 5 分钟失败短名单（上限 64 条），最近失败过的路由自动跳过，设置页显示失败码与剩余时间。同一次子代理内的运行期换路由仅旧版 DSH 保留。
- **适配 DSH 0.2.2-alpha.2**：思考等级改走 `agentOptions.reasoningEffort`；新宿主 `agent/request` 已改为只读，不再在瀑布后尝试改路由。兼容声明继续保持 `>=0.1.1-rc.2`、不设上界，兼容基线上移至 `0.2.2-alpha.2`。
- **模型配置**：最近删除记录支持逐条删除，修复模型编辑与恢复流程。
- **移动端会话管理**：条目改为「标题 + 标签 + 操作钮」同一行、操作钮缩小到右上角，meta 独占下一行整行展示；长路径不再压到按钮下。
- **移动端备份维护**：备份条目与工具栏改为信息/操作分行、按钮等宽，设置页头行给右上角关闭钮留位。
- **移动端设置页**：标签条恢复真实触摸横滑（官方 `navList` 不再充当嵌套滚动容器）。
- **移动端输入框**：子代理/后台任务芯片不再被标题栏裁剪；模型钮在宽度足够时完整展示「图标 + 模型名 + 思考等级」，不再因差几个像素被收成紧凑态。
- **运行要求**：DSH `0.2.2` 起宿主自身要求 Node.js `>=24.9`（本插件仍为 `>=22`）。

## npm 安装 / Install from npm

在 DSH 插件管理页输入 / Enter in the DSH plugin manager:

```text
@gehennawu/dsh-service@2.1.2
```

或使用命令行（将 `web` 换成实际 Profile 名）/ Or use the CLI (replace `web` with your profile name):

```bash
dsh plugin --profile web add @gehennawu/dsh-service@2.1.2
```

请使用精确版本号，避免 pnpm 发布观察期选择旧版本。宿主半查询逻辑需重新加载插件或重启 DSH 后生效；前端界面更新后请刷新页面。

Use the exact version to avoid pnpm's release cooldown selecting an older release. Host-side query changes require reloading the plugin or restarting DSH; refresh the page after updating the frontend.

## Added / Fixed

- **Dispatch-time subagent routing**: pick a route before dispatch by quota health and candidate priority; add a 5-minute recent-failure shortlist (max 64 entries) so recently failed routes are skipped, with failure code and remaining time shown in settings. In-agent route switching remains only on legacy DSH.
- **DSH 0.2.2-alpha.2 compatibility**: reasoning effort now goes through `agentOptions.reasoningEffort`; the new host makes `agent/request` read-only, so route changes after the waterfall are no longer attempted. The declared range stays `>=0.1.1-rc.2` with no upper bound, and the verified baseline moves to `0.2.2-alpha.2`.
- **Model configuration**: recent deleted records can be removed one by one; model editing and restore flow fixed.
- **Mobile session manager**: rows put title + tags + actions on one line with compact actions at the top-right, while meta takes the full next line; long paths no longer run under the actions.
- **Mobile backup maintenance**: entries and the toolbar split info and actions into separate rows with equal-width buttons; the settings header leaves room for the top-right close button.
- **Mobile settings**: the tab bar responds to real touch swiping again (the official `navList` no longer acts as a nested scroll container).
- **Mobile composer**: subagent/background-task chips are no longer clipped by the title bar; the model button shows icon + full model name + reasoning effort whenever it fits, instead of collapsing over a few pixels.
- **Runtime requirements**: DSH `0.2.2` hosts require Node.js `>=24.9` (this plugin still requires `>=22`).
