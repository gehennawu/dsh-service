# v1.6.1（2026-09-15）

v1.6.1 是一批手机端体验收口：大屏手机上的模型选择与统计行、滑动沉浸的收起与回显、以及会话详情里工具消息的默认折叠。

## 新增 / 修复

- **手机端 · 统计行保持一行并把宽度用满**：输入框下方「轮/步·tok/s ｜ tok·缓存命中」这一行原先被官方自带的左右各 32px 内边距吃掉 76px，只能各自固定截断。现在收紧这一行自身的边距与间距，两枚统计按需分宽共占满整行：≥420px 视口不再截断数字，更窄机型按比例让位而不是各自硬截断，全程一行、不横向滚动。
- **手机端 · 模型选择按钮收成图标**：428~440 的 Plus / Pro Max 机型此前常显模型名、不收起——插件的移动端布局把会话列拉宽了 52~56px，官方自带的窄容器收起规则在这些机型上永远不会触发。现在按官方窄容器同形态在 ≤480px 收成图标（481px 以上仍显示模型名与推理等级，读屏信息不丢）。
- **手机端 · 滑动沉浸的收起与回显不再错位**：收起输入框改用「让出占位 + 淡出」，修掉两处偶发症状——收起后会话底部残留一大段空白；回显时最后一段被输入框压住。
- **手机端 · 点「回到底部」浮钮后输入框立即回来**：此前点回底不触发回显，要手动上滑一点再下滑、有时试几次才出来。现在点回底即回显并对齐到内容末尾；已经停在会话末尾时往回一点即回显（不再等满阈值）。
- **手机端 · 移除底部悬浮胶囊钮**：「隐藏/显示对话框」的常驻把手去掉，收起/回显仍由滑动、点回底浮钮、聚焦输入框三条路径控制。
- **会话详情 · 工具消息默认折叠**：工具调用与工具结果折叠成一行计数块，点击展开或收起；搜索命中落在折叠块内会自动展开并保持高亮——长会话的详情页不再被工具参数刷屏。
- **移动端诊断条**：`?dshsvc-mobile-debug=1` 的浮动诊断条新增「回显来路」（滑动 / 到底 / 聚焦 / 回底钮），用于定位「输入框为什么没回来」。

## 兼容性与升级提示

- 本版本已按代码路径适配 DSH `0.1.1-rc.2` 至 `0.1.5-rc.2`；DSH `0.1.6-alpha.0` 及以上版本尚未验证。
- 从 1.6.0 升级无需修改任何配置。本批改动只作用于 <1024px 视口的移动端适配（且滑动沉浸仍按原有开关位默认关闭）与会话详情面板，桌面端行为不变。
- 本版本通过 379 项自动化测试。

## Added / Fixed

- **Mobile · the stats line stays on one line and uses the full width**: the row under the composer ("turns/steps · tok/s | tok · cache hit") used to lose 76 px to the official 32 px side padding and could only truncate each chip at a fixed size. That row's own padding and gaps are now tightened and both chips share the whole row: from ~420 px up no digit is truncated, narrower phones give up width proportionally instead of hard-truncating each chip, and the row never wraps or scrolls horizontally.
- **Mobile · the model picker collapses to an icon**: on 428~440 Plus / Pro Max devices the model name used to stay visible — the plugin's mobile layout widens the conversation column by 52~56 px, so the official narrow-container collapse rule never fires there. It now collapses at ≤480 px exactly like the official narrow form (from 481 px up the model name and reasoning effort still show, and the accessible label is preserved).
- **Mobile · scroll immersion no longer misaligns while hiding and revealing**: hiding the composer now yields its layout space with a fade, fixing two intermittent symptoms — a large blank stretch left at the bottom of the conversation while hidden, and the last paragraph being covered by the composer on reveal.
- **Mobile · tapping the "Back to bottom" button brings the composer back immediately**: it previously did not reveal at all, requiring a manual swipe up and then down, sometimes several tries. A tap now reveals and aligns to the content end; when already sitting at the end of the conversation, a single small backward nudge is enough (no full threshold needed).
- **Mobile · removed the floating pill button**: the resident "hide/show composer" handle is gone; hiding and revealing are still driven by swiping, tapping the back-to-bottom button, and focusing the composer.
- **Session details · tool messages collapse by default**: tool calls and tool results collapse into a one-line counted block that expands or collapses on click, and a search hit inside a collapsed block opens it automatically while keeping the highlight — long-session detail pages are no longer flooded by tool arguments.
- **Mobile diagnostics chip**: the floating chip behind `?dshsvc-mobile-debug=1` now reports the reveal reason (swipe / arrival / focus / back-to-bottom), to diagnose "why did the composer not come back".

## Compatibility and upgrade notes

- This release has been adapted for DSH `0.1.1-rc.2` through `0.1.5-rc.2`; DSH `0.1.6-alpha.0` and later are unverified.
- Upgrading from 1.6.0 requires no configuration change. This batch only affects the mobile adaptation below a 1024 px viewport (scroll immersion still defaults to off behind its existing switch) and the session details panel; desktop behavior is unchanged.
- This release passes all 379 automated tests.
