# v1.5.0（2026-09-10）

v1.5.0 带来 DSH 0.1.5-rc.1 兼容适配，将移动端右栏手势切换至官方右侧栏，并改进子代理模型配置保留和窄屏版本信息排版。

## 新增 / 修复

- **适配 DSH 0.1.5-rc.1**：兼容新的 Session persistence handle、会话格式 V3、官方右侧栏（Rightbar）和 Connection/webServer 生命周期契约；同时保留旧宿主形态的兼容路径。
- **保留子代理模型草稿**：在「自定义 / 跟随主模型 / 初始」模式之间切换并保存时，不再销毁已保存的供应商、模型、思考等级和回退路由；切回自定义模式可继续使用原配置。
- **移动端右栏手势改用官方接口**：右缘手势现在驱动 DSH 官方 Rightbar，不再依赖 `dsh-better-sidebar` 的专有 DOM。官方右栏未挂载时，或旧版 DSH 没有该能力时，右栏开启手势（向左滑）按设计不可用。
- **修复右栏折叠态误判**：官方右栏折叠时面板和收起按钮可能仍常驻 DOM；现在按服务状态、展开标记和官方属性判断，避免把开左栏误判成关右栏或重复翻转。
- **改进窄屏版本卡布局**：版本信息区使用自身可用宽度进行响应式换行，长版本链接、状态和兼容性声明在窄设置面板中不再互相挤压。
- **收紧兼容性扫描**：跳过随 DSH 内核发布的 `@deepseek-ai/*` 官方包，避免把官方大包误报为第三方兼容性问题。
- **补强 0.1.5 连接通道注册**：适配新的调用者 Fiber 生命周期，并让 `webServer` 保持可选；无该服务时不影响纯 RPC 能力。

## 兼容性与升级提示

- 本版本已按代码路径适配 DSH `0.1.1-rc.2` 至 `0.1.5-rc.1`；`0.1.6-alpha.0` 及以上版本尚未验证，版本卡会将其标红警示。
- DSH 0.1.5 的 V3 会话格式不是旧宿主可读格式。升级后产生的 V3 会话不能假定可被旧版 DSH 读取；升级前请按需保留备份并避免在旧宿主上回退使用。
- 本版本通过 336 项自动化测试。

## Added / Fixed

- **DSH 0.1.5-rc.1 compatibility**: support the new Session persistence handle, V3 session format, official Rightbar, and Connection/webServer lifecycle contract while retaining compatibility paths for older host shapes.
- **Preserved subagent model drafts**: switching and saving between Custom, Follow main model, and Initial modes no longer destroys the saved provider, model, reasoning effort, or fallback routes; the original custom configuration is restored when returning to Custom.
- **Official Rightbar for mobile gestures**: right-edge gestures now drive the official DSH Rightbar instead of `dsh-better-sidebar`-specific DOM. The rightbar open gesture (leftward swipe) is intentionally unavailable when the official Rightbar is not mounted or when running on an older DSH without that capability.
- **Fixed collapsed-Rightbar detection**: the official panel and its close button can remain mounted while collapsed; detection now uses service state, expanded markers, and official attributes to avoid misrouting a left-drawer gesture or toggling twice.
- **Improved narrow version-card layout**: the version section now wraps according to its own available width, preventing long links, status text, and compatibility notices from colliding in narrow settings panels.
- **Tightened compatibility scanning**: bundled `@deepseek-ai/*` packages are skipped so official large packages are not reported as third-party compatibility failures.
- **Hardened connection registration for 0.1.5**: account for the caller Fiber lifecycle while keeping `webServer` optional, so RPC-only operation remains available without that service.

## Compatibility and upgrade notes

- This release has been adapted for DSH `0.1.1-rc.2` through `0.1.5-rc.1`. DSH `0.1.6-alpha.0` and later are unverified; the version card marks those versions with a red warning.
- DSH 0.1.5 V3 sessions are not a format that older hosts can be assumed to read. After upgrading, do not assume newly created V3 sessions are readable after rolling back to an older DSH; keep backups as needed before upgrading or rolling back.
- This release passes all 336 automated tests.
