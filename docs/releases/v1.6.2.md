# v1.6.2（2026-09-15）

v1.6.2 是一批 DSH `0.1.6-alpha.1` 适配与会话管理补强：新版外壳的移动端选择器与子代理派发时序对齐、归档会话可以恢复，并把三处会话列表状态不同步修掉。

## 新增 / 修复

- **适配 DSH `0.1.6-alpha.1`（已真机验收）**：移动端 composer 底行触发钮采用双哈希并存（`Sh0Q9G_` + `JObwrW_`）；子代理派发记录适配官方 `agent/created` 改为 `ctx.serial` 异步串行派发后的时序，并在取不到异步上下文时给出防御告警而不是静默失效；插件兼容扫描补充三个新破坏面（`agent/session-start`、`@deepseek-ai/dsh-code-runtime`、`@deepseek-ai/dsh-e2b`）。
- **归档会话恢复（取消归档）**：会话管理新增「恢复」动作，单项与批量都可执行；宿主按能力探测调用官方 `workspaceRegistry.unarchiveSession`，老版本 DSH 上隐藏入口并给出说明；恢复成功后本地各视图缓存即时同步，不需要重新拉取整表。
- **修复 · 恢复期间切换筛选导致列表错乱**：恢复请求在途时切换「全部 / 仅归档」，列表不再按发起时的旧视图增删该行。
- **修复 · 已加载的归档会话没有恢复入口**：已归档且仍在运行中的会话现在也能恢复；删除仍保持「仅非运行中会话」的限制。
- **修复 · 删除归档会话后官方侧留下幽灵行**：删除成功后主动补发官方会话移除事件、并清掉归档集合里的死 id，官方侧栏与「已归档会话」设置页无需刷新浏览器即可反映最新状态。

## 兼容性与升级提示

- 本版本已按代码路径适配 DSH `0.1.1-rc.2` 至 `0.1.6-alpha.1`，并在真实机器上完成 `0.1.6-alpha.1` 验收；`0.1.6-alpha.2` 及以上版本尚未验证，越界运行时版本卡标红警示。
- 从 1.6.1 升级无需修改任何配置。归档恢复只在 DSH `≥0.1.6` 的宿主上出现，老版本宿主行为与 1.6.1 一致。
- 本版本通过 386 项自动化测试。

## Added / Fixed

- **Adapted to DSH `0.1.6-alpha.1` (verified on a real deployment)**: the mobile composer's bottom-row trigger keeps two hashes side by side (`Sh0Q9G_` + `JObwrW_`); subagent dispatch recording follows the official `agent/created` now dispatched asynchronously and serially through `ctx.serial`, and a missing async context logs a defensive warning instead of failing silently; the plugin compatibility scan gains three new breakage entries (`agent/session-start`, `@deepseek-ai/dsh-code-runtime`, `@deepseek-ai/dsh-e2b`).
- **Archived-session restore (unarchive)**: the session manager gains a Restore action, available per row and in batch; the host calls the official `workspaceRegistry.unarchiveSession` behind a capability probe, hides the entry on older DSH hosts with an explanation, and refreshes every local view cache on success without refetching the whole list.
- **Fixed · list corruption when switching filters mid-restore**: switching between All and Archived while a restore is in flight no longer adds or removes that row according to the view the request started in.
- **Fixed · loaded archived sessions had no restore entry**: archived sessions that are still running can now be restored; deletion keeps its "non-running sessions only" restriction.
- **Fixed · deleting an archived session left a ghost row on the official side**: a successful delete now re-emits the official session-removed event and clears the dead id from the archive set, so the official sidebar and the "Archived sessions" Settings page reflect the new state without a browser reload.

## Compatibility and upgrade notes

- This release has been adapted for DSH `0.1.1-rc.2` through `0.1.6-alpha.1`, and `0.1.6-alpha.1` has been verified on a real deployment; DSH `0.1.6-alpha.2` and later are unverified, and the version card flags them in red.
- Upgrading from 1.6.1 requires no configuration change. Archived-session restore only appears on DSH `≥0.1.6` hosts; older hosts behave exactly as in 1.6.1.
- This release passes all 386 automated tests.
